# BranchWise AI

Multi-role operations platform for branch managers, HR, and general managers — reports, onboarding, company forms, and branch ops hub.

## Stack

- Next.js 15 (App Router)
- Supabase
- TypeScript / Tailwind CSS

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Build

```bash
npm run build
```
